# ownAplane user guide

The user guide now lives in the app, as the **Help** section: https://ownaplane.eu/help

Its articles are Markdown files in [`content/help/`](../content/help), one folder per language
(`en/`, `bg/`, same file names). The order and categories are in `lib/help/articles.ts`. Update
the articles in both languages together with the features they describe.
